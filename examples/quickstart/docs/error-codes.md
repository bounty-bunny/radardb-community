# Error codes

| Code | Meaning | What to do |
|---|---|---|
| QS-1001 | Token expired | Create a new personal access token in Settings → Tokens |
| QS-2040 | Attachment too large | Attachments are limited to 250 MB per file |
| QS-3117 | Workspace is read-only | An owner must update the payment method |
| QS-4502 | Webhook signature mismatch | Recompute the HMAC-SHA256 signature with your signing secret |

# PR #3342: Batch promotion lookup in cart summary

Repository: acme/checkout-svc
Author: Daniel Kim (dkim)
Merged: 2026-09-16 as commit 7c04e9b
Fixes: INC-2041

## Description
Replaces the per-line getPromotions call with a single getPromotionsForCart(cartId) call that loads all promotion rules with WHERE line_id = ANY($1). Queries per checkout drop from 41 to 3 for a typical cart. Adds a query-count assertion to the cart summary integration test.

## Benchmark
p99 cart summary latency on staging: 1,840 ms before, 210 ms after.

# PR #3190: Use row locks for stock reservations

Repository: acme/inventory-svc
Author: Mei Tanaka
Merged: 2026-08-05 as commit 4d2e9a1
Fixes: INC-1988

## Description
Replaces the Redis reservation lock (TTL 2 seconds) with SELECT ... FOR UPDATE SKIP LOCKED on the stock_levels row inside the reservation transaction. Contended requests now fail fast with OUT_OF_STOCK instead of double reserving.

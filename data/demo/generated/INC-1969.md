# INC-1969: Cart notes migration locked carts table

Severity: Sev2
Date: 2026-07-10
Duration: 159 minutes
Incident commander: Kwame Mensah
Services: cart-svc

## Summary
Add-to-cart failed for 6 minutes during a schema migration.

## Root cause
The migration added a column with a volatile default, which rewrote the table under an exclusive lock.

## Resolution
Re-ran the migration with a nullable column and a background backfill.

# INC-1800: Checkout latency during autumn sale warm-up

Severity: Sev3
Date: 2026-03-05
Duration: 20 minutes
Incident commander: Kwame Mensah
Services: checkout-svc, edge-gateway

## Summary
Checkout p99 latency reached 1.4 s for 22 minutes while traffic ramped up before the sale.

## Root cause
edge-gateway autoscaling used a CPU target of 80%, so new pods arrived after queues had already built up.

## Resolution
Lowered the autoscaling CPU target to 60% and added scheduled pre-scaling before announced sales.

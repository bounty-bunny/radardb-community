# INC-1930: Clock skew rejecting auth tokens

Severity: Sev2
Date: 2026-06-12
Duration: 162 minutes
Incident commander: Sofia Alvarez
Services: auth-svc

## Summary
Token validation failed for about 4% of requests on two nodes.

## Root cause
chrony was disabled on a new node image, so clocks drifted by 90 seconds.

## Resolution
Re-enabled chrony in the base image and added a clock offset alert.

# INC-1904: Disk full on orders-db replica

Severity: Sev2
Date: 2026-05-23
Duration: 38 minutes
Incident commander: Mei Tanaka
Services: orders-db

## Summary
A read replica stopped replaying WAL and reporting queries returned stale data for 2 hours.

## Root cause
The log volume filled because log_min_duration_statement was set to 0 during a debugging session and never reverted.

## Resolution
Reverted the setting and added disk usage alerts at 80%.
